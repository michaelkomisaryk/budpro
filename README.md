# БудПроєкт

Система автоматизації процесів планування, контролю та супроводу будівельних проєктів.
Django + MySQL + HTML/CSS (без фронтенд-фреймворків).

## Структура проєкту
```
manage.py
requirements.txt
.env.example                 <- шаблон налаштувань бази (скопіюйте в .env)
config/
    settings.py              <- налаштування, підключення до MySQL
    urls.py
    wsgi.py
    __init__.py              <- підключає драйвер PyMySQL
construction/
    models.py                <- Project, Task, Worker, Material, Expense
    forms.py                 <- ModelForm для кожної моделі
    views.py                 <- усі сторінки (функції)
    urls.py
    admin.py
    migrations/0001_initial.py
    management/commands/seed_demo.py   <- необов'язкові демо-дані
    templates/construction/  <- base.html та всі сторінки (в т.ч. material_catalog.html)
    templates/registration/login.html
    static/construction/css/style.css
    static/construction/js/app.js
```

## Запуск у PyCharm на Windows
1. Відкрийте папку проєкту: File -> Open. Створіть інтерпретатор: File -> Settings -> Project -> Python Interpreter -> Add Interpreter -> Virtualenv.
2. У вікні Terminal в PyCharm: `pip install -r requirements.txt`
3. У MySQL створіть базу (MySQL Workbench або консоль):
   `CREATE DATABASE construction_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
4. Скопіюйте `.env.example` у `.env` та впишіть пароль root у рядок `DB_PASSWORD=`.
5. `python manage.py migrate`
6. `python manage.py createsuperuser` (створіть свого користувача)
   або `python manage.py seed_demo` (демо-дані: директор admin / admin12345, працівники sklyar, koval, melnyk, boyko... / worker12345)
7. `python manage.py runserver`
8. Відкрийте http://127.0.0.1:8000/ і увійдіть.

## Ролі
* **Директор** — користувач з правами адміністратора (його ви створюєте командою `createsuperuser`).
  Керує всім: проєкти, завдання, працівники, матеріали, витрати, табель, зарплати, звіти.
* **Працівник** — користувач, прив'язаний до запису на сторінці «Працівники». Заходить під своїм логіном і бачить
  лише своє: призначені завдання, свої години, матеріали (без цін) свого проєкту та розрахунок своєї зарплати.
  Бюджет, витрати, звіти й чужі дані йому недоступні.

### Як додати працівника з входом
1. Директор: «Працівники» -> «Новий працівник».
2. Заповнює дані, **проєкт**, **ставку (грн/год)**, а також **логін і пароль** для входу.
3. На сторінці «Завдання» призначає йому завдання (виконавцем може бути лише працівник цього ж проєкту).
4. Працівник заходить на сайт, у «Мої години» записує, скільки відпрацював.

### Як рахується зарплата
Зарплата за місяць = сума (години × ставка) за всіма записами цього місяця.
Ставка фіксується в момент запису годин, тому підвищення ставки не змінює минулі місяці.
Директор бачить усе на сторінці «Зарплати» і кнопкою «внести у витрати» додає зарплату у витрати проєкту
(повторне натискання лише оновлює суму, дубля немає).

## Каталог матеріалів
Під час додавання матеріалу можна вибрати позицію з каталогу (назва, одиниця та ціна підставляться самі)
або ввести свій матеріал вручну й за бажанням поставити галочку «Зберегти як свою позицію в каталозі».
Стандартні позиції додаються автоматично командою `python manage.py migrate`.
Після кожного оновлення проєкту виконуйте `python manage.py migrate`.

## Важливо про облік
Матеріали (кількість × ціна) — це облік матеріалів проєкту. Фактичні гроші вносяться окремо на сторінці «Витрати».
Контроль бюджету рахується тільки за витратами, тому одна покупка не враховується двічі.
